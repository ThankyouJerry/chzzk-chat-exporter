# chzzk-chat-exporter

치지직 VOD 채팅을 구간별로 수집해 CSV 파일로 내보내는 Chrome 확장 프로그램입니다.

이 프로젝트는 [ClipCatcher](https://github.com/ThankyouJerry/ClipCatcher)와 함께 사용하는 보조 도구입니다. 채팅 데이터를 추출해 방송 분석, 하이라이트 탐색, 후처리 워크플로우에 활용할 수 있습니다.

## 주요 기능

- 치지직 VOD 공개 채팅 수집
- 전체 방송 또는 시작/종료 시간 범위 지정
- 경과시간과 공개 닉네임을 포함한 CSV 생성
- 20MB를 넘는 CSV 자동 분할
- 브라우저 내부 처리 및 자동 다운로드

## 출력 형식

```csv
Timestamp,User ID,Message
00:05:30.000,user123,안녕하세요!
00:05:35.123,user456,ㅋㅋㅋㅋ
```

`Timestamp`는 방송 시작 기준 경과시간입니다.

## 설치

1. 저장소를 내려받거나 Release ZIP의 압축을 풉니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. `개발자 모드`를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다`를 누르고 폴더를 선택합니다.

## 사용 방법

1. 치지직 VOD URL 또는 VOD 번호를 입력합니다.
2. 필요한 경우 `HH:MM:SS` 형식으로 시작과 종료 시간을 입력합니다.
3. `채팅 수집 시작`을 누릅니다.
4. 수집이 끝나면 CSV가 자동으로 다운로드됩니다.

## 권한

- `storage`: 마지막 URL과 수집 진행 상태를 로컬에 저장합니다.
- `downloads`: 생성한 CSV 파일을 내려받습니다.
- `https://api.chzzk.naver.com/*`: 사용자가 입력한 VOD의 메타데이터와 공개 채팅을 조회합니다.

채팅 내용은 제작자가 운영하는 별도 서버로 전송하지 않습니다. CSV 생성은 확장 프로그램 내부에서 처리합니다.

## 연동 흐름

1. `chzzk-chat-exporter`로 채팅 CSV를 추출합니다.
2. 채팅 분석 도구에서 반응 구간을 확인합니다.
3. 영상 구간 다운로드는 [ClipCatcher](https://github.com/ThankyouJerry/ClipCatcher)를 사용합니다.

## 제한 사항

- 치지직 API 변경이나 접근 제한에 따라 수집이 일시적으로 실패할 수 있습니다.
- 삭제되었거나 채팅 다시보기가 제공되지 않는 VOD는 수집할 수 없습니다.
- 수집한 채팅의 이용과 공유에는 치지직 이용약관 및 각 방송자의 권리가 적용됩니다.
